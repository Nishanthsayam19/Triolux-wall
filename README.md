# TRIOLUX Wall Printer

TRIOLUX is a full-stack wall-printing service application
developed for an AWS DevOps deployment project.

## Technologies

- React + Vite — Frontend
- Node.js + Express — Backend
- PostgreSQL — Database
- Docker — Containerization
- GitHub — Source Code Management
- AWS EC2 — Backend Deployment (planned)
- Amazon S3 — Frontend Hosting (planned)
- Amazon CloudFront — CDN and HTTPS (planned)

## Features

- Responsive wall-printing website
- Wall-printing image gallery
- Price calculator at INR 400 per square foot
- Customer booking form
- Backend REST API
- PostgreSQL booking storage

## Application Architecture

User -> React Frontend -> Node.js API -> PostgreSQL

## Local Ports

Frontend: 5173
Backend: 3000
PostgreSQL: 5432
